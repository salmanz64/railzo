# 🚆 Railzo

Modern railway ticket booking app built with Flutter.

Railzo allows users to search trains, check real-time seat availability, select seats, book tickets, and make secure online payments.  
Built using MVVM architecture, Riverpod state management, Firebase backend services, and Stripe payment integration.

## ✨ Features

- Search trains between stations
- Real-time seat availability
- Seat selection
- Online ticket booking
- Secure Stripe payments
- Firebase Authentication
- Cloud Firestore backend
- Fast and responsive UI
- Clean and scalable MVVM architecture
